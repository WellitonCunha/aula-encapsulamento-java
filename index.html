03 · Conceito

O que é encapsulamento?

É o princípio de esconder detalhes internos de um objeto e controlar a forma como seus dados podem ser acessados ou modificados.

Analogia: você não altera diretamente o saldo do banco. Você solicita uma operação como depositar() ou sacar(), e o sistema verifica as regras.

05 · private

Protegendo o atributo

public class Pessoa {
    private String nome;
    private int idade;
}

Antes

pessoa.idade = -50;

Depois

pessoa.idade = -50;
// Erro de acesso

O atributo privado só pode ser acessado diretamente dentro da própria classe.

07 · Validação

Getter e setter não são tudo

public void setIdade(int idade) {
    if (idade < 0 || idade > 150) {
        System.out.println("Idade inválida.");
        return;
    }

    this.idade = idade;
}
Ideia central: o método pode validar antes de alterar o estado.
08 · this

O que significa this?

private int idade;

public void setIdade(int idade) {
    this.idade = idade;
}

this.idade

É o atributo do objeto atual.

idade

É o parâmetro recebido pelo método.

09 · Prática

ContaBancaria

public class ContaBancaria {
    private String titular;
    private double saldo;

    public ContaBancaria(String titular) {
        this.titular = titular;
        this.saldo = 0;
    }

    public double getSaldo() {
        return saldo;
    }
}

O saldo é privado. Agora precisamos decidir como ele pode mudar.

10 · Prática

Comportamentos do objeto

public void depositar(double valor) {
    if (valor <= 0) {
        System.out.println("Valor inválido.");
        return;
    }

    saldo += valor;
}

public boolean sacar(double valor) {
    if (valor <= 0 || valor > saldo) {
        System.out.println("Saque inválido.");
        return false;
    }

    saldo -= valor;
    return true;
}
Perceba: não precisamos de setSaldo(). O saldo muda por operações válidas.

12 · Insight

Encapsulamento ≠ apenas private

Menos adequado

private double saldo;

public void setSaldo(
    double saldo
) {
    this.saldo = saldo;
}

Qualquer valor pode ser colocado.

Mais orientado a objeto

public void depositar(
    double valor
) { ... }

public boolean sacar(
    double valor
) { ... }

O objeto controla suas regras.
